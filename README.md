# Dream Studio Design — bozza sito

Prima bozza statica del nuovo sito commerciale di Dream Studio Design.

## Stato

- solo HTML/CSS/JS vanilla;
- nessun framework;
- nessun backend;
- nessun form attivo;
- immagini attuali sostituite da segnaposto grafici: nella versione successiva vanno usati lavori reali Dream Studio Design;
- struttura pensata per conversione: intento del cliente → servizi → casi studio → metodo → contatto.

Aprire `index.html` direttamente nel browser per vedere la pagina.

## Passi successivi

1. inserire logo reale e fotografie dei progetti;
2. scegliere 3–5 casi studio da trasformare in pagine complete;
3. validare headline e CTA;
4. aggiungere pagine servizio SEO;
5. collegare contatti/form e tracking solo dopo la validazione del frontend.
